# ⏳ Pomodoro Productivity Tool

A simple yet effective productivity tool that helps you stay focused using the Pomodoro Technique! Work in 25-minute intervals with 5-minute breaks and take a longer break after four cycles. This tool is designed to boost productivity, reduce burnout, and enhance focus by breaking tasks into structured, manageable sessions.
Developed a productivity application featuring a Pomodoro timer, task prioritization, progress tracking, and achievement badges.
Integrated AI-powered task planning and personalized study recommendations to help users organize learning goals and improve focus.

## 🚀 Features

-  ✅ **Time Management**  Splits work into 25-minute intervals with 5-minute breaks, reducing procrastination and improving focus.

-  ✅**Progress Tracking** Visual checkmarks to track completed Pomodoros, offering motivation and a sense of accomplishment.

- ✅ **Customizable Intervals**  Adjust work and break durations to fit personal preferences and different task types.

- ✅ **User Notifications**  Get audio/visual alerts when work sessions end and when it's time to take a break.

## 🛠️ Tech Stack

- **Tkinter (GUI) 🎨**

## 🚀 Getting Started

### Prerequisites

- Python 3.10 or compatible version
- Git (optional)

### 1. Clone the Repository

```bash
git clone https://github.com/Aditigarg18/pomodoro.git
cd pomodoro
```

### 2. Install Dependencies

If your application uses Windows notifications, install:

```bash
python -m pip install winotify
```

### 3. Run the Application

```bash
python main.py
```

Ensure that `tomato.png` and `skill learning.py` are in the correct locations.

## 🔐 API Configuration

This project can use the following APIs for AI-powered productivity and learning features:

- **Google Gemini API** – For AI-powered task planning and productivity suggestions.
- **YouTube Data API v3** – For searching relevant learning videos.

### Setup

1. Create a `.env` file in the project root directory.
2. Add your API keys:

   ```env
   GEMINI_API_KEY=your_gemini_api_key
   YOUTUBE_API_KEY=your_youtube_api_key
   ```
